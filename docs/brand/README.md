## Проверки и регистрация

Точный веб-поиск NeuroGateway 15.10 не дал в выданной выборке подтверждённой коллизии, но это **не** поиск по реестру и не доказательство свободного имени/домена/social handle. [Официальные поисковые сервисы Роспатента](https://rospatent.gov.ru/index.php/ru/faq/gde-samostoyatelno-provesti-poisk-tovarnyh-znakov-v-internete) и [платформа](https://searchplatform.rospatent.gov.ru/trademarks) — следующий gate: словесное/фонетическое/изобразительное сходство для относящихся к продукту классов, заключение специалиста, скрин/экспорт результатов. Выполненная юридическая clearance не заявляется.

План имён: neurogateway.ru / neurogateway.com / neurogateway.io. Доступность и цена требуют проверки у выбранного регистратора в момент заказа. Администратор — организация, не личный временный аккаунт. План DNS: api→LB gateway, docs→документация, status→отдельный status сервис; TLS/CAA/MFA/автопродление после регистрации. Social handles проверить и закрепить отдельно; аккаунты не созданы.

Регистрация требует названия/реквизитов организации, администратора, регистратора и лимита оплаты, которых в поручении нет. Домены не куплены, DNS не изменён, право на бренд не получено. Перед платным заказом нужен конкретный доступный домен/стоимость и подтверждение владельца. Логотип и токены готовы для согласования и уже доступны в Web; отдельного Figma design system не создано.
