## 1. Назначение и контекст

В рамках масштабирования платформы (Семинар 7) за Командой 2 (Маркус Филипп) закреплена функциональная область интеграции с поставщиками моделей.  
Задача `E05-01` реализует ключевой межкомандный контракт между ядром шлюза (Core Data Plane) и адаптерами LLM-провайдеров:
- Интерфейс `ProviderAdapter`: `BuildRequest`, `SendRequest`, `ParseResponse`, `ParseStreamEvent`, `MapError`, `ExtractUsage`, `Capabilities`.
- Реестр адаптеров и конфигурация эндпоинтов.
- Базовая реализация и контрактные тесты через `mock-provider` (`internal/mockprovider/`).
