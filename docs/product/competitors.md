## Отзывы и качество доказательств

[Trustpilot OpenRouter](https://uk.trustpilot.com/review/openrouter.ai) содержит разные пользовательские сообщения, в том числе о расходах/доступе. Они не доказывают дефекты сервиса: неизвестны настройки ключей, auto top-up, контекст и результат обращения. [Один отзыв AITUNNEL](https://otzovik.com/review_18563292.html) хвалит простоту подключения; его независимость и типичный опыт не подтверждены. Для GenAPI/ProxyAPI/VseGPT/BotHub независимая репрезентативная выборка не собрана. Маркетинговые отзывы не заменены выдуманными оценками. Вывод исследования — темы для интервью и теста, без рейтинга надёжности брендов.

## Пять гипотез ценности → PRD

1. Аудируемая связь generation→usage→price version→проводка→refund. Проверить с интеграторами на сверке расходов; PRD ledger и reporting. Не утверждается, что конкуренты этого не имеют.
2. Строгий capability catalog и предсказуемый422 вместо потери параметра. Проверить golden fixtures выбранных endpoints; PRD integration persona.
3. Бюджет ключа, безопасный при параллельных hold/capture. Проверить race и доступный баланс; PRD startup. Наличие budgets у конкурентов уже отмечено, уникальность не доказана.
4. Явная цена/регион fallback и запрет перехода после первого токена. Проверить аварийный demo; PRD reliability.
5. Воспроизводимый onboarding SDK + n8n за5мин с диагностикой request_id. Проверить timed user test, а не только скопировать пример; PRD activation.

RUB платежи и единый API — рыночный минимум, не самостоятельное УТП. Для полного DoD задачи ещё нужны подтверждение неизвестных коммерческих ячеек/одинаковая ценовая корзина, более широкая выборка отзывов и командное утверждение гипотез. Полнота матрицы не маскирует полноту доказательств.

## Решение по поручению пользователя

Матрица и5гипотез приняты от имени Ильи в рамках делегированного ревью; неизвестные данные и неподтверждённая уникальность остаются явно отмечены. [Проверка](../delivery/review-2026-10-15.md).
