## Доска и Git

Проверенные разрешённые переходы текущего workflow: Создано → В работе / Закрыто; В работе → Создано / Закрыто / Выполнено. «Закрыто» и «Выполнено» — завершённые состояния. Отдельные «К работе», «Ревью», «Тестирование» в проверенных карточках не предлагаются; пока этап проверки фиксируется в описании и checklist. Требуемую полную цепочку Бэклог → К работе → В работе → Ревью → Тестирование → Готово нужно настроить отдельно. Настройки workflow администратора этим изменением не менялись.

Trunk based: main, короткие feature ветки (codex/*), PR не дольше одного спринта, маленькие Conventional Commits. Формат title `feat(contracts): ...`/`docs(product): ...`; CODEOWNERS и шаблоны в .github, hooks `make hooks`. SemVer 0.x до стабильного v1, breaking API требует новой major API версии и migration guide. Секреты и персональные payload не коммитить. CI зелёный до merge, контрактные файлы генерируются из одного источника.

Автор готовит PR с проблемой, результатом, проверкой и ограничениями. Принимающий проверяет acceptance, запускает воспроизводимые команды и записывает результат. Время отмечается фактическое, без выдуманных person-hours. Блокер старше 2 рабочих дней — в daily и комментарии эпика E00. Изменение scope — запись причины и влияния в PRD/roadmap + ссылка в задаче.
