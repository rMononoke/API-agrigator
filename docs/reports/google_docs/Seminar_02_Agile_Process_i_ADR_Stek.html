3. Вклад участников команды

  • Ерофеев Илья (Lead Architect): Разработал C4-архитектурную модель (Context, Container, Component). Оформил ключевой ADR (ID24_API-22) по выбору Go 1.23 в качестве основного языка высоконагруженного шлюза (минимальное потребление памяти, горутины, p99 latency < 15 мс) и PostgreSQL для финансового учёта.
  • Маркус Филипп (Lead Integrations): В рамках ADR обосновал использование JSON Schema Draft 2020-12 для спецификации контрактов данных вместо голого OpenAPI, что позволило обеспечить динамическую кодогенерацию и строгую валидацию полиморфных сообщений.
  • Деревцов Андрей (Financial & Data): Сформировал сводный документ NFRs (ID24_API-27): доступность сервиса 99.9%, целевое время обработки запроса p50 < 5 мс, RPO = 0 (нулевая потеря финансовых транзакций), RTO < 60 секунд.
  • Улитин Максим (Team Lead): Сконфигурировал доску задач в Сфере: дорожки Backlog, Ready for Dev, In Progress, Review/Test, Done. Утвердил критерии DoR (Definition of Ready) и DoD (Definition of Done).
