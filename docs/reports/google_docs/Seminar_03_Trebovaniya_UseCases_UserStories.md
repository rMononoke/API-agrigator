## 4. Персональный вклад участников команды
* **Улитин Максим (Team Lead):** Декомпозировал требования на User Stories с acceptance criteria: сценарий бесшовной авторизации по единому API-ключу, сценарий прозрачного списания средств в рублях, сценарий автоматического переключения при падении провайдера (failover).
* **Маркус Филипп (Lead Integrations):** Специфицировал функциональные Use Cases для работы с моделями: 1) Синхронный вызов Chat Completions; 2) Потоковый вывод токенов Server-Sent Events (SSE) в реальном времени; 3) Мультимодальный ввод (текст + изображения высокого разрешения Base64/URL); 4) Вызов внешних инструментов (Function / Tool Calling).
* **Ерофеев Илья (Lead Architect):** Связал Use Cases с контейнерной архитектурой C4. Развернул локальную среду docker-compose (ID24_API-36) с PostgreSQL, Redis и Mock-серверами для быстрого тестирования сценариев всеми членами команды.
* **Деревцов Андрей (Financial & Data):** Специфицировал финансовые Use Cases: предавторизация средств (hold) перед отправкой запроса к LLM и окончательный клиринг по фактическому количеству возвращённых токенов.
