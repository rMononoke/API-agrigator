# Семинар 7. Масштабирование управления разработкой ПО

**Проект:** NeuroGateway — единая платформа-агрегатор языковых моделей.  
**Тема:** Моделирование роста проекта от одной учебной команды к нескольким командам, совместно развивающим платформу.

---

| **Карта межкомандных зависимостей** | Матрица технических зависимостей, направления потоков данных, критический путь | Маркус Ф. / Ерофеев И. |

---

## 2. Ключевые решения по масштабированию

1. **Разделение на 4 стрим-команды:**
   - **Team 1: Core & Data Plane** (Шлюз, маршрутизация, стриминг SSE, кэш) — тимлид направления: Ерофеев И.
   - **Team 2: Model Adapters & Provider Integration** (Адаптеры провайдеров, каноническая LLM-схема, нормализация usage) — тимлид направления: **Маркус Ф.**
   - **Team 3: Platform, Billing & Ledger** (Финансовый движок, учет usage, кошельки, PG/ClickHouse) — тимлид направления: Деревцов А.
   - **Team 4: Control Plane & Developer Experience** (ЛК разработчика, админ-панель, аутентификация, биллинг-интерфейсы) — тимлид направления: Улитин М.

2. **Общий слой контрактов (Contract-First):**
   - Библиотека `packages/contracts` содержит спецификации OpenAPI 3.1 и JSON Schema. Любое межкомандное взаимодействие строится на автогенерируемых DTO с обратной совместимостью (SemVer).

3. **Владелец межкомандных зависимостей:**
   - Архитектурный комитет (Ерофеев И. + Маркус Ф.) отвечает за согласование breaking changes в контрактах шлюза и адаптеров.
